# غرفة التحميض

صفحة بتنزّل صوت أو فيديو من يوتيوب وفيسبوك. الصفحة موجودة على GitHub Pages، لكن التحميل نفسه بيحتاج سيرفر `server.py` شغال على جهازك.

الصفحة: https://sherifazb.github.io/darkroom-downloader/

## التشغيل على اللابتوب (ويندوز)

1. نزّل Python من python.org. وقت التثبيت علّم على "Add Python to PATH".
2. نزّل ffmpeg وحطه في PATH (أو من CMD: `winget install ffmpeg`).
3. نزّل الملفات `server.py` و`requirements.txt` من الريبو، وافتح CMD في نفس الفولدر:
   `pip install -r requirements.txt`
   ثم `python server.py`
4. سيب CMD شغال، وافتح الصفحة من Chrome أو Edge (مش سفاري ولا الموبايل). لو المتصفح سأل عن السماح بالوصول للشبكة المحلية اختار سماح.

## ملاحظات

- السيرفر بيقبل بس لينكات يوتيوب وفيسبوك، وبيرفض أي موقع تاني.
- الحد الأقصى 150 ميجا و20 دقيقة لكل ملف، وتحميلين في نفس الوقت.
- يوتيوب ممكن يرفض من أي سيرفر على الإنترنت (IP استضافة). على جهازك بيشتغل عادة.
- لو الصفحة كتبت "السيرفر مش شغال" يبقى `server.py` مش شغال.
